# TV3 supplemental unit checks
Run from frontend after npm ci: `node tests/tv3-extra/button-classes.test.mjs` (repeat for each *.test.mjs). The loader transpiles actual TypeScript with the installed TypeScript compiler and executes isolated helpers with explicit dependency mocks. No network or real browser is used. These checks cover button classes, sort accessibility, clock, navigation, service guide assets, search, prices, popularity, image URLs, booking query and storage. They do not prove React rendering, API integration or a successful build. Added tests are outside the original transfer manifest and require team approval before inclusion.
